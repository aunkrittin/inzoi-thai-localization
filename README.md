# ม็อดภาษาไทยสำหรับ inZOI

ม็อดนี้เพิ่มคำแปลภาษาไทยให้เมนู การสร้างตัวละคร การแต่งบ้าน การทำงาน และการใช้ชีวิตในเกม

## ดาวน์โหลด

ดาวน์โหลดม็อดเวอร์ชันล่าสุดได้ที่ [GitHub Releases](https://github.com/aunkrittin/inzoi-thai-localization/releases/latest)

## วิธีติดตั้ง

1. ดาวน์โหลดและแตกไฟล์ `inZOI-Thai-Localization-0.1.1.zip`
2. นำโฟลเดอร์ `Thai_Localization_7F01A001` ไปไว้ที่ `%USERPROFILE%\Documents\inZOI\Mods\88849\`
3. เปิดเกม เข้า **Creative Mode > Mod** แล้วกด **Validate**
4. เปิดใช้งานม็อดและรีสตาร์ตเกม
5. ไปที่ **Settings > Language** แล้วเลือก **ไทย**

## วิธีถอนการติดตั้ง

ปิดเกมแล้วลบโฟลเดอร์ `%USERPROFILE%\Documents\inZOI\Mods\88849\Thai_Localization_7F01A001`

ม็อดนี้ไม่แก้ไขไฟล์เกมต้นฉบับ ดู [ปัญหาที่ทราบ](KNOWN_ISSUES.md) หรือแจ้งปัญหาได้ที่ [Issues](https://github.com/aunkrittin/inzoi-thai-localization/issues)
